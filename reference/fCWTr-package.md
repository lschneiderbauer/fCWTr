# fCWTr: Fast Continuous Wavelet Transform

Enables the usage of the fast continuous wavelet transform, originally
implemented in the 'C++' library 'fCWT' by Lukas Arts. See Arts, P.A.
and Van den Broek, E.L. (2022)
[doi:10.1038/s43588-021-00183-z](https://doi.org/10.1038/s43588-021-00183-z)
for details.
