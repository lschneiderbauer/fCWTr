# Print the scalogram

[`print()`](https://rdrr.io/r/base/print.html) prints its argument and
returns it invisibly (via `invisible(x)`).

## Usage

``` r
# S3 method for class 'fcwtr_scalogram'
print(x, ...)
```

## Arguments

- x:

  The "fcwtr_scalogram" object resulting from
  [`fcwt()`](https://lschneiderbauer.github.io/fCWTr/reference/fcwt.md)
  to print.

- ...:

  further arguments passed to or from other methods.

## Value

Returns the argument `x` invisibly.
